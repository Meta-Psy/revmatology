# К-10 · Публичные страницы ленивыми кусками

**Родитель:** `К-10` → `К-09` → `Л-01` · **Реестр возврата:** `_specs/PLAN.md` · **Ветка:** `feat/public-lazy-pages` · **Поручение:** Alex 2026-09-15 («Делаем до»), срок — заморозка 2026-09-21

## Цель

После `К-09` вход `index-*.js` весит 740 кБ / 186 кБ gzip. Замер состава (`f1c89be`, размер модулей до минификации): `react-dom` 548 КиБ, страницы `src/pages` 452 КиБ, `axios` 100, `i18next` 78, `react-router` 77, шапка и подвал 52, три локали 39, просмотр PDF `src/components/pdf` 34 КиБ. Посетитель страницы конгресса качает код всех 17 публичных страниц и просмотрщик PDF, который нужен двум из них. Вход должен содержать только оболочку сайта и главную; остальные страницы грузятся при переходе. Проверяется при каждой сборке.

## Решения

1. **Главная (`Home`) остаётся во входе, остальные публичные страницы — `React.lazy`**, по куску на страницу (включая `Login`, `Register`). Главная — самая частая точка входа. Ленивая главная добавила бы на `/` ещё один запрос, который стартует только после загрузки и выполнения входа: при задержке 0,2–0,5 с (TLS у нас 0,5–1,4 с) это дороже, чем ~10 КиБ gzip, которые главная весит во входе (0,1–0,25 с при 40–100 КБ/с).
2. **`Suspense` внутри `Layout`, вокруг вложенных `Routes`.** Шапка и подвал на месте, пока грузится страница; заглушка — спокойный блок в области `main` с минимальной высотой, чтобы подвал не прыгал. Переходы в React Router 7 идут через `startTransition`, поэтому при переходе между страницами остаётся видна старая страница, пока не придёт новый кусок, без мигания заглушки.
3. **Boundary на сбой загрузки куска.** Обрыв на медленном канале отклоняет `import()`; без boundary падает всё приложение. Boundary стоит внутри `Layout` (шапка остаётся, можно уйти на другую страницу), текст через `t()` во всех трёх локалях: «Страница не загрузилась» + «Обновить страницу». Сбрасывается при смене адреса, иначе после ошибки не уйти по меню. Старые куски после выкатки не пропадают (`scp-action` кладёт `dist` поверх, без удаления), поэтому основной случай — обрыв сети.
4. **Сторож сборки.** `vite-plugins/adminChunkGuard.js` уже роняет сборку за админку во входе и за превышение бюджета. Добавить правило: во входе нет модулей `src/pages/*`, кроме `Home.jsx`, и нет `src/components/pdf/*`. `ENTRY_GZIP_BUDGET` опустить до нового замера + ~10 КиБ запаса.
5. **TDD, сценарно.** Тест сторожа (страница во входе → ошибка), тест App: переход на ленивую страницу рисует её внутри `Layout`, сбой `import()` показывает boundary с шапкой, смена адреса снимает ошибку. Существующие тесты страниц не должны зависеть от того, ленивая страница или нет.

## Вне рамок

- Ленивые локали (грузить только активный язык, −25 КиБ до минификации): отдельный узел, если понадобится.
- Предзагрузка кусков соседних страниц в простое: на медленном канале конкурирует с картинками главной.
- nginx: кэш `/assets` на год, `http2` → `О-09`, после 2026-09-27. Пока кэша нет, каждый кусок при повторном заходе проверяется запросом 304 — одна задержка на кусок; после `О-09` уйдёт.
