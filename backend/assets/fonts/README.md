`Caveat-Medium.ttf` (OFL 1.1, см. `OFL.txt`) — статический экземпляр wght=500 из https://raw.githubusercontent.com/google/fonts/main/ofl/caveat/Caveat%5Bwght%5D.ttf, пересборка: `fonttools varLib.instancer "Caveat[wght].ttf" wght=500 --static -o Caveat-Medium.ttf`.

В Caveat нет узбекского ʻ (U+02BB) — при отрисовке он заменяется на ‘ (U+2018), см. `substitute_missing` в `functions/certificate_pdf.py`.
